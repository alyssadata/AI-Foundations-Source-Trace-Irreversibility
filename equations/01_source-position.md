# 1. Source Position

Let **S₁** denote the actual source position of the first trajectory.

**S₁ = standing at t₀**

Here, **S₁** is not merely the abstract state “standing.” It is the standing state at its original historical coordinate: before the first displacement in **T₁** occurs.

This distinction matters because a later tile may reproduce the same visible configuration without occupying the same source position.

Formally:

**Source(T₁) = S₁**

and if a later state **S₂** reproduces the same standing configuration:

**State(S₂) = State(S₁)**

does not imply:

**S₂ = S₁**

The source is therefore both a state and a position within an actual provenance line.
